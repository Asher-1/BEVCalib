## 问题3回答：标定补偿量是否自适应？

### ❌ 当前模型：补偿量不会随bias线性增加

**测试结果**：
- Roll: **过度补偿**（Jacobian=-1.199，超过100%）
- Pitch: **几乎无补偿**（Jacobian=-0.026，仅2.6%）
- Yaw: **部分补偿**（Jacobian=0.547，54.7%）

**实际表现**：
```
假设人工修改外参（模拟行程误差）：
  初始外参: Roll=0°, Pitch=0°, Yaw=0°
  手动修改: Roll=+5°, Pitch=+5°, Yaw=+5°（模拟车辆行驶导致的外参漂移）

模型的实际补偿（基于Jacobian）：
  Roll: +5° → 补偿 -6.0°（过度补偿，结果变成-1°）❌
  Pitch: +5° → 补偿 -0.13°（几乎不补偿，结果仍是+4.87°）❌
  Yaw: +5° → 补偿 +2.74°（部分补偿，结果剩+2.26°）⚠️
```

**结论**：**模型没有学到真正的自适应补偿能力**

## 根本原因分析

### Shortcut的3种表现形式

#### 形式1：记忆训练集平均offset（Pitch）

```python
# 模型学到的shortcut
prediction = base_offset  # 固定值，无论输入如何变化

# 而非真正的几何推理
prediction = f(img, pc, intrinsic, extrinsic)
```

**证据**：Pitch Jacobian=-0.026（对外参扰动无响应）

#### 形式2：过拟合训练扰动范围（Roll）

```python
# 训练时：扰动范围±5°
# 测试时：扰动±10°（超出训练范围）

模型在±10°时过度补偿（Jacobian=-1.199）
说明在±5°内可能OK，但泛化到±10°时崩溃
```

#### 形式3：依赖特定图像特征而非几何（所有轴）

```python
# Shortcut路径
prediction = MLP(DINOv2_features)  # 直接从图像特征预测offset

# 正确路径
correspondence = CrossAttn(img, pc, extrinsic)  # 建立2D-3D对应
prediction = GeometricSolver(correspondence, intrinsic)  # 几何求解
```

**证据**：整体Jacobian=-0.226（远低于0.85警戒线）

## 为什么MEDW看起来好，但Jacobian差？

### 陷阱：训练集泛化 ≠ 真实世界鲁棒性

| 维度 | MEDW测试 | Jacobian测试 | 真实部署 |
|------|----------|--------------|----------|
| 外参扰动 | **±5°** | **±10°** | **±20°甚至更大** |
| 数据分布 | 训练集同分布 | 超出训练范围 | 完全OOD |
| 模型表现 | 0.26° ✅ | [WEAK] ❌ | **大概率失败** ❌ |

**实际场景**：
```
车辆行驶10,000公里后：
- 摄像头支架松动：Roll可能漂移±10°
- 颠簸路段震动：Pitch可能瞬时±15°
- 急转弯离心力：Yaw可能偏移±20°

当前模型在这些情况下：
❌ Roll: 过度补偿，导致误判
❌ Pitch: 几乎无补偿，外参严重偏离
⚠️ Yaw: 部分补偿，误差仍大
```

## 🎯 解决方案：克服shortcut

### 方案1：扩大训练扰动范围（治标）

```yaml
# 当前配置
angle_range_deg: 5  # ±5°

# 改进配置
angle_range_deg: 15  # ±15°（覆盖真实场景）

# 但问题：
# - 更大范围会降低小角度精度
# - Jacobian可能仍然[WEAK]（如果模型架构有问题）
```

### 方案2：显式几何监督（治本）⭐

```python
# 添加投影一致性loss
def projection_consistency_loss(pred_R, img, pc, intrinsic):
    """
    强制模型学习真正的几何约束
    """
    # 用预测的R投影点云到图像
    pc_img = project(pc, pred_R, intrinsic)
    
    # 提取对应的图像特征
    img_feat_at_proj = sample(img_features, pc_img)
    
    # 强制图像特征和点云特征一致
    loss = MSE(img_feat_at_proj, pc_features)
    
    return loss

# 这会迫使模型：
# 1. 正确建立2D-3D对应关系
# 2. 无法通过记忆shortcut来降低loss
# 3. Jacobian自然会提升到>0.85
```

### 方案3：对抗性训练（增强鲁棒性）

```yaml
# 训练时动态增加扰动
augment_adversarial_rotation: true
adversarial_rotation_range: [5, 20]  # 动态范围

# 每个batch随机选择扰动范围
# 迫使模型学习全范围的自适应补偿
```

### 方案4：Multi-task学习（验证几何理解）

```python
# 主任务：标定
loss_calib = rotation_loss(pred_R, gt_R)

# 辅助任务：投影深度估计
pred_depth = model.predict_depth(img, pc, pred_R)
loss_depth = depth_loss(pred_depth, gt_depth)

# 总loss
total_loss = loss_calib + 0.5 * loss_depth

# 深度估计任务会强制模型：
# - 理解投影几何
# - 无法靠记忆完成（每个场景深度不同）
```
