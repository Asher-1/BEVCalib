# V39 优化前后对比

## 配置对比

| 参数 | 原配置 | 优化后 | 改进理由 |
|------|--------|--------|---------|
| **batch_size** | 24 | **48** | +2×加速，充分利用显存 |
| **learning_rate** | 4.8e-4 | **5.7e-4** | 按√batch_size缩放 |
| **num_epochs (Exp1)** | 100 | **60** | 平衡收敛与速度 |
| **trans_range** | 0.20 | **0.0** | 只优化旋转（用户需求） |
| **eval_epoches** | 10 | **15** | 减少评估开销 |
| **cosine_T0** | 50 | **30** | 适配更少epochs |
| **warmup_epochs** | 10 | **6** | 适配更少epochs |

## 训练质量预期

| 指标 | 原方案 | 优化方案 | 风险评估 |
|------|--------|---------|---------|
| **Jacobian** | >0.85目标 | >0.80预期 | 🟡 略降但可接受 |
| **MEDW** | <0.5°目标 | <0.5°预期 | ✅ 不受影响 |
| **收敛性** | 100ep充分 | 60ep略紧 | 🟡 需监控early stop |
| **泛化能力** | 数据增强全开 | 数据增强全开 | ✅ 不变 |

## 风险与缓解

| 风险 | 概率 | 缓解措施 |
|------|------|---------|
| **batch_size=48 OOM** | 中 | 备用方案：bs=40 (4.2h仍达标) |
| **60ep收敛不足** | 低 | 监控val loss，必要时延长到80ep |
| **大batch_size泛化差** | 低 | LR已按√bs缩放，数据增强全开 |

## 决策树

```
启动训练（batch_size=48）
  |
  ├─ OOM？
  |   ├─ 是 → 降低到bs=40，重新启动
  |   └─ 否 → 继续
  |
  ├─ Exp1结束后（60ep）
  |   ├─ Jacobian>0.80？
  |   |   ├─ 是 → ✅ 成功，启动Exp2
  |   |   └─ 否 → 延长到80ep或解冻PointGPT
  |   |
  |   └─ MEDW<0.5°？
  |       ├─ 是 → ✅ 继续
  |       └─ 否 → 检查训练曲线
  |
  └─ 3个实验完成（~7.5h）
      └─ 总结：1个工作日内完成验证 ✅
```
