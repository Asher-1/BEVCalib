# BEVCalib v35 技术报告：打破 Shortcut Learning 的自适应外参标定

## 1. 问题定义

### 1.1 背景
BEVCalib 是一个基于 BEV (Bird's Eye View) 表示的相机-LiDAR 外参在线标定系统。核心任务是：给定初始外参 `T_init`（可能存在误差），通过神经网络预测一个矫正量 `T_pred`，使最终外参 `T_init * T_pred` 逼近真值 `T_gt`。

### 1.2 致命问题：Shortcut Learning
v30~v34 版本存在一个严重缺陷——**shortcut learning（捷径学习）**：
- 模型学到了一个固定的矫正偏移量（~0.3°），无论 `T_init` 如何变化
- 表现为：手动改变 `T_init` 的外参误差（如增加 5° pitch 偏差），模型仍然只矫正 ~0.3°
- 数值 Jacobian `∂correction/∂bias ≈ 0.0005`，远低于理想值 1.0

### 1.3 根因分析
信息瓶颈：`T_init` 仅通过 BEV 投影间接影响特征，经过多层卷积和 transformer 后，`T_init` 的变化信号被严重衰减。模型无法感知"当前 T_init 有多大偏差"，只能学到训练集的统计平均矫正量。

## 3. v35 核心方案：ExplicitTInitEncoder

### 3.1 架构设计
绕过 BEV 投影瓶颈，直接将 `T_init` 的 RPY（Roll/Pitch/Yaw）编码注入预测头：

```
                    ┌─────────────────────────────┐
Image ──→ Backbone ──→ BEV Projection ──→ ──┐      │
                                             ├─ Transformer ──→ Pool ──→ [feat ⊕ tinit_feat] ──→ Pred Head
LiDAR ──→ PC Encoder ──→ BEV Projection ──→ ┘      │
                                                     │
T_init ──→ RPY提取 ──→ Fourier Features ──→ MLP ───┘
```

### 3.2 关键组件

**ExplicitTInitEncoder**：
1. 从 4×4 变换矩阵提取 RPY 角度（弧度）
2. 多频率 Fourier 特征编码：`[sin(2^k * rpy), cos(2^k * rpy)]`，k=0..5
3. 两层 MLP：`RPY(3) → Fourier(36) → Linear(128) → GELU → Linear(64)`
4. 输出与 BEV pooled feature 拼接后送入预测头

### 3.3 为什么有效
- **直接路径**：RPY 信息不经过 BEV 投影，避免信息衰减
- **Fourier 编码**：多频率编码保留角度的精细变化，防止 MLP 对小角度差异不敏感
- **后期融合**：在 transformer 处理完 BEV 特征后才融合，保持 BEV 特征的空间理解能力

## 5. Phase2 对比实验：TInitSensitivityLoss

### 5.1 设计
对比式损失函数，强制中间特征对 `T_init` 变化敏感：
```
L = ||feat_dist - α * rpy_dist||²
```

### 5.2 结果（v35b, weight=0.5）
| 指标 | v35 (Phase1) | v35b (+SensLoss) | 
|------|-------------|------------------|
| Val Best | **2.05°** | 2.07° |
| Jacobian | **0.283** | 0.120 |
| 1° Rate | **99.5%** | 88.6% |
| 10° Rate | 6.4% | **14.2%** |

**结论**：SensLoss 在 1-5° 范围削弱了自适应矫正，但改善了大偏差（>7°）和基线噪声。与主损失竞争效应明显。

## 8. 已知局限与后续方向

1. **大偏差瓶颈**：>5° 偏差矫正率 <32%，矫正量饱和在 ~1.5°
2. **Yaw 轴弱势**：Jacobian 仅 0.072（Roll 的 1/5），可能需要 Yaw 专用增强
3. **距理想 Jacobian=1.0 仍有差距**：当前 0.283 是 28.3% 效率
4. **推理时迭代开销**：RAFT 模式增加 N 次 GRU+MLP forward，需评估延迟影响
