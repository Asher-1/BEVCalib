## 4. 为什么 G3 (dinov2-small) 比 H8 (dinov2-base) 好？

### 4.1 模型复杂度与过拟合

- dinov2-base (86M backbone) 在有限的泛化测试数据上更容易产生 correlated noise
- dinov2-small (22M backbone) 产生更独立的帧间误差, 更适合 √N 聚合
- DANN 虽然减小了 H8 的单帧 domain gap, 但引入了 bias (噪声不够中心化)

### 4.2 √N Scaling 差异

- G3: MEDW400→MEDW800 降低 23.3%, 接近理论值 1-1/√2=29.3%
- H8: MEDW400→MEDW800 降低 19.6%, 低于理论值
- 结论: G3 的噪声更接近 i.i.d., 聚合效果更好

### 4.3 800→1600 的边际递减

- G3: 仅降 6.1% (0.066°→0.062°), 远低于理论 29.3%
- H8: 降 11.9% (0.074°→0.065°), 相对更好
- 原因: 短序列 (N<1600) 的全序列平均已饱和, 拉高了整体误差
- 6 个长序列 (N=1600) 中 G3 从 MEDW800 平均 0.064° 降至 MEDW1600 0.049°
  → 长序列的 800→1600 改善约 24%, 接近理论值 29%

## 5. 部署建议

### 5.1 推荐配置

```
Model:      V29-G3 (dinov2-small + partial unfreeze last2 + strong jitter)
Params:     49.7M (checkpoint ~400MB)
Method:     MEDW (axis-angle median)
max_frames: 1600 (最高精度) 或 800 (精度/延迟平衡)
```

### 5.2 精度-延迟权衡

| 配置 | 预计精度 | 帧数需求 | 适用场景 |
|---|---:|---:|---|
| MEDW400 | 0.086° | 400帧 (~13s@30fps) | 快速标定 |
| MEDW800 | 0.066° | 800帧 (~27s@30fps) | **推荐默认** |
| MEDW1600 | 0.062° | 1600帧 (~53s@30fps) | 最高精度 |

### 5.3 代码入口

```python
from utils.bevcalib_inference import load_bevcalib_with_aggregation

model, agg, epoch = load_bevcalib_with_aggregation(
    "ckpt_best_val.pth",
    max_frames=1600,   # or 800 for faster convergence
)

for img, pc, init_T, post_T, K in sequence_frames:
    pred_T = model(img, pc, init_T, post_T, K)
    agg.add(pred_T)
    if agg.ready:
        calibration = agg.aggregate()     # (4,4) robust result
        confidence = agg.get_confidence() # per-axis std in degrees

agg.reset()  # ready for next sequence
```

## 7. 技术细节

### 评估流程

1. 模型推理: `evaluate_checkpoint.py` → 每帧预测 T_pred (4×4)
2. 数据保存: `all_T_pred_gt.npz` (推理前保存, 防中断丢失)
3. 时序聚合: 滑动窗口 MEDW/SVD/Trimmed 多种方法自动对比
4. 报告生成: `run_generalization_eval.py` 自动汇总

### 性能优化 (temporal aggregation)

- scipy Rotation 模块级导入 (消除 per-call import 开销)
- 预计算 axis-angle 向量 per sequence (消除 O(n×w) 重复转换)
- SVD cumulative sum 优化 (O(1) 窗口均值)
- 预估加速: 20-50x for median/trimmed, 5-10x for SVD
