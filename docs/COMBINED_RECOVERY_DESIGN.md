# MEDW + ZD补偿 + 迭代 组合方案设计

## 1. 部署 Pipeline 三阶段

```
┌─────────────────────────────────────────────────────────────────┐
│ Phase 1: Per-Trip ZD 标定 (前 50 帧, 无扰动)                      │
│   init_T = GT, 收集模型预测偏差                                    │
│   → per-trip ZD_median (R,P,Y)                                    │
│   → 可选: Affine TTA 进一步优化 (6 params, <1s)                   │
│   预期: 去除 85-95% 的 per-trip ZD                                 │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ Phase 2: 逐帧迭代推理 (inject 扰动后恢复)                          │
│   for each frame:                                                 │
│     init_T = T_perturbed                                          │
│     for iter in 1..5:                                             │
│       T_pred = model(frame, init_T)                               │
│       T_comp = compensate_zd(T_pred, ZD_median)  # 减 ZD           │
│       init_T = T_comp                                             │
│     输出: T_comp (单帧校正结果)                                    │
│   预期: inject 3° → 单帧残差 0.10-0.20°                           │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ Phase 3: MEDW 时序聚合 (每 50-200 帧输出一次最终标定)               │
│   收集 Phase 2 的 T_comp                                          │
│   → axis-angle 空间中取 robust median                              │
│   → 最终外参 T_final                                              │
│   预期: 随机噪声再降 30-50%, 输出精度 0.05-0.08°                   │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 各阶段实测效果 (V62 基准)

| 阶段 | 指标 | 实测值 | 来源 |
|------|------|--------|------|
| 基线 ZD | inject 0° 误差 | 0.58-0.87° | iterative_recovery_v62 |
| Phase 1 | per-trip ZD | 0.12-0.84° (各 trip 不同) | generalization_c1_v62 |
| Phase 1 | ZD 补偿后残余 | ~0.15° (median) | affine_tta_eval |
| Phase 2 | inject 3° + ZD + 3iter | mean=0.22°, rec<0.1°=31% | V66 report |
| Phase 2 | inject 3° + Affine + 5iter | mean=0.22°, rec<0.1°=15% | affine_tta_eval |
| Phase 3 | MEDW200 无 inject | mean=0.41° | deploy_simulation |

**关键发现**: MEDW 对系统性 ZD 无效 (0.71° → 0.41° 仅降 42%)，ZD 必须在 Phase 1 去除。

## 3. 可达 Recovery 估算

### 误差分布模型

实测: mean=0.22°, rec<0.1°=15% → 推算 std≈0.12°

要达到 95% < 0.1°: 需要 **mean < 0.06° 且 std < 0.03°**

## 4. 推荐实施路径

### 短期 (本周, 无需重训练)

```
V62 + per-trip ZD中值补偿 + 5iter + MEDW50
预期: rec<0.1° ≈ 50-60%
```

实现: 直接用 `zd_online_calibration_test.py` + MEDW 后处理

### 中期 (V67/V68 训练完成后)

```
V68 + per-trip Affine TTA + 5iter + MEDW100
预期: rec<0.1° ≈ 90-95%
```

### 长期 (如果仍不够)

```
V68 + LoRA TTA + 5iter + MEDW200 + 好trip优先部署
预期: rec<0.1° ≈ 95%+
对 ZD>0.5° 的 trip (00,03,07) 考虑:
  - 增加 adapt 帧数到 200
  - 或收集同学型车数据微调
```

## 5. 关键认知修正

| 之前的认知 | 修正 |
|-----------|------|
| V62+TTA+5iter = 97.6% Recovery | 这是**均值** Recovery, 阈值<0.1°仅 15-31% |
| TTA 去除 95% ZD | 实测 per-trip ZD 去除 70-85%, 残余 0.10-0.15° |
| MEDW 显著降误差 | MEDW 只降随机噪声, 对系统性 ZD 几乎无效 |
| 单帧迭代即可达标 | 需要 **ZD补偿 + 迭代 + MEDW** 三件套 |
| 所有 trip 同等可达 | D-type trip (ZD<0.3°) 可达, A-type (ZD>0.7°) 困难 |
